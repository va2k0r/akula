# Russian sonar new-contact voice

The audio clips in this directory were generated offline on 2026-08-16 with
the Piper `ru_RU-dmitri-medium` neural voice.

- Voice model: https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/dmitri/medium
- Dataset license: CC0
- Runtime: Piper; used only during asset generation and not distributed with
  the game
- Sample rate: 22,050 Hz mono
- Delivery format: AAC-LC in an M4A container

The runtime assembles one fixed report and exactly three bearing digits:

`Акустик — центральному. Новый контакт. Пеленг: ноль, четыре, семь.`

English meaning:

`Sonar to central. New contact. Bearing: zero, four, seven.`
